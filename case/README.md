# Evidence index: Case File 06

Everything here is fictional. Lessons read these files through `lantern.case`. Files marked
*planned* are not written yet; they are listed so every chapter knows where its evidence will be.

| File | What it is | First used | Status |
|---|---|---|---|
| `00-briefing.md` | Inspector Varma's briefing note, 13 July | 01 | written |

| `statements/` | The bank statements the questions are answered from, carried from Case Files 02 and 05 | 01 | planned |
| `questions/` | The question set that depends on memory and context, with signed answers | 02 | planned |
| `memory-log/` | The access and write log of the memory store, with the session records behind each write | 12 | planned |
| `custody/` | DS Iyer's suspension and badge records, consistent with Case File 03 | 20 | planned |
| `review/` | The case review of chapter 22 | 22 | planned |

Rules for every file: evidence is read-only. A lesson that needs a changed copy of anything
makes one under `.scratch/`. Stores and indexes are built under `.scratch/` and are never
committed.
